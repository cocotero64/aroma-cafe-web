
# Contributing to Aroma Café

## Branch Naming
- main: Stable production branch.
- develop: Integration branch.
- feature/*: New features.
- hotfix/*: Urgent production fixes.

## Commit Messages
Use the following prefixes:
- feat: New functionality
- fix: Bug fixes
- style: CSS and visual changes
- docs: Documentation changes

## Pull Requests
1. Create feature branches from develop.
2. Make at least two commits per feature.
3. Open a pull request into develop.
4. Request a teammate's review.
5. Use a merge commit after approval.
6. Do not commit directly to main or develop.
